v0.1.0-dev.15:
- Icon - New circledInfoIcon (also dist/icons/circled-info.svg): a circled "i" for notice marks; was left out of dev.14 by mistake

v0.1.0-dev.14:
- Button - The default size is now the compact 31px button (radius 5px, 8px padding, 6px gap, 12px regular text); the icon button is 32x32. Every default and primary button shifts about 4px taller than before
- Button - variant="primary" is the same size as the default and differs only in colour; the old large form-button look (10px 24px, 16px semibold) is gone
- Button - New variant="strong" (grey #8b8b8b, bold) and size="action" (150x36 at 13px, for dialog actions); new tokens color.strong.*, size.radius.xs, size.button.action-width and action-height
- Tokens - size.button.pad-x (--ui-size-button-pad-x) is removed

v0.1.0-dev.13:
- Menu section, list box section - title is now a ReactNode, so a heading can carry an icon (with visually hidden text for screen readers); string titles render unchanged

v0.1.0-dev.12:
- Icon - New dotIcon (also dist/icons/dot.svg): a plain filled dot for status marks such as an unsaved-changes indicator; about 6px at size sm, and it follows currentColor so it stays visible in forced-colors
- Menu item, submenu item - New tooltip and tooltipOnlyWhenTruncated: a Grille-skinned tooltip opens on hover (400 ms) and at once on keyboard focus of the row itself, with no nested focusable; with tooltipOnlyWhenTruncated it shows only when the label is cut off; a submenu row hides it while its flyout is open
- Menu item, submenu item - description no longer sets a native title= tooltip: it is screen-reader text only, and a row shows a tooltip only when given tooltip

v0.1.0-dev.11:
- Menu submenu - New maxHeight prop (default --ui-size-submenu-max-height, 480px, never taller than the screen space): a long flyout scrolls inside its popup
- Menu - New MenuSection with a title: a sticky, non-focusable group heading that labels its items

v0.1.0-dev.10:
- Popover - Pressing the trigger of an open non-modal Popover closes it instead of closing then reopening it
- Autocomplete - The search field fills its container, so it fits a fixed-width popover
- Tooltip - New Tooltip and TooltipTrigger (React Aria), skinned like a popup, with rich content; hover and focus show it, Esc hides it
- Menu - New selectionMode, selectedKey and onSelectionChange: a single-select Menu marks the chosen item with a check
- Select, dropdown triggers - The chevron flips while the popup is open (any button with aria-expanded and a direct-child chevron icon)

v0.1.0-dev.9:
- Icon - New Icon component and size tokens, with a vendored set of 20 icons and THIRD_PARTY_NOTICES for their licenses
- Icon - Plain-SVG export (@weblings/grille/icons/*.svg) for pages without React
- Drawer, Select, Disclosure, Menu submenu, Callout, StatusMessage - Render Grille icons instead of text glyphs
- Button - .ui-button is now an inline flex row so icons sit beside labels
- Slider - Track fill

v0.1.0-dev.8:
