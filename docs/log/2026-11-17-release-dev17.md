## Lessons

- Parallel agents must not each run npm install: give every worktree its node_modules before fan-out (agent-coordination)
- Worktrees under .claude/ need a hand-made HEAD checkout and a scoped test run in the main checkout (agent-coordination)
- A new layout default changes every placement outside its usual container, so check each one (engineering-hygiene)
- A test that starts a React Aria keyboard drag must end it, or every later test in the file breaks (components)
