# gripIcon, a drag handle

Id: 2026-11-17-grip-icon

`Grille-83g.9`. Aurora's controls panel draws drag handles from a local six-dot SVG. Searched for a
shared-set source first: Vidstack media-icons 0.10.0 `raw/` (menu-horizontal, menu-vertical, settings-menu
are the nearest, no grip or drag) and the Zest repo tree (all 1608 svg paths in free and pro: only
`more`, `horizontal-more`, `menu`, `sort-*`, no grip or drag). Neither has one, so the mock's own
geometry is used: `src/icons/grip.ts`, viewBox `0 0 8 14`, eight circles r=1.3 at x 1.5 and 6.5, y 1, 5, 9, 13.
Contributed by the owner under Grille's MIT licence and listed as Grille's own in `THIRD_PARTY_NOTICES`
(the existing dot icon is listed with it).

The 8x14 shape is not square, so it is `tight: true`: Icon draws it in the square layout box with no
overhang, and the default aspect ratio scales it to the box height and centres it. Exported from
`src/icons/index.ts`, also `dist/icons/grip.svg`.

Icon-count assertions went from 23 to 24 (`src/ui.test.tsx`, `scripts/icon-svg.test.mjs`,
`scripts/vendor-icons.test.mjs`). Fixture "grip on a row" in `src/Icon.fixture.tsx` (the catalog shows it too).
