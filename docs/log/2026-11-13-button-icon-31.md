# Icon-only Button is 31px

Id: 2026-11-13-button-icon-31

`Grille-kca`. From Aurora-u8jx.11: the default icon-only Button (`data-icon`) was 8px padding + glyph, so 32px with
the 16px glyph, 1px over the 31px text button (8 + 15 line + 8); Aurora's top bar came out 49px not 48.

Now `.ui-button[data-icon]` is a 31px square: new token `size.button.icon-size` (`--ui-size-button-icon-size`),
used for width and height, padding 0, the glyph centred by the button's flex layout. `size="sm"` icon buttons keep
their padded size (`width/height: auto`). Square chosen for the open width question. Aurora can drop its bar height
override and the 49px bar.

- Not checked: the rendered height in a browser or in Aurora's bar (jsdom has no layout).
