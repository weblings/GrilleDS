# dotIcon for status marks

Id: 2026-11-13-dot-icon

`Grille-ky2.6`. Aurora marks unsaved effects with a 6px dot (`.s6-dot`, an empty element with a
background colour), which Windows forced-colors replaces, so the only unsaved mark vanishes. An SVG
filled with `currentColor` follows the forced text colour, so a Grille icon fixes it with no CSS.

New `dotIcon` (`src/icons/dot.ts`, exported, also `dist/icons/dot.svg`): one filled circle, r=3.6 on
the 24 grid, Origin "drawn for Grille". **No new Icon size.** A non-tight sm Icon draws a 20px glyph
(12px box + 4px overhang each side), so r=3.6 gives a 6px dot at `size="sm"` (about 7px at md).
Decorative by default; the consumer supplies screen-reader text (Aurora: `MenuItem` description).

Icon-count assertions went from 21 to 22 (`src/ui.test.tsx`, `scripts/icon-svg.test.mjs`,
`scripts/vendor-icons.test.mjs`). Fixture "dot beside label" in `src/Icon.fixture.tsx`.
