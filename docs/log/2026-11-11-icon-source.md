# Icon source: vendored Vidstack, Zest and Aurora SVGs

Id: 2026-11-11-icon-source
Status: shipped 2026-11-11 — Grille-ky2.1 closed. Exported from the package root by Grille-ky2.2.

## What landed

- `src/icons/`: 19 icons, one module each, exporting an `IconData` (`viewBox`, `paths`) so consumers
  import only what they use and can pass their own object of the same shape.
- 14 Vidstack icons generated by `scripts/vendor-icons.mjs` from `media-icons@0.10.0` (pinned
  devDependency only, no runtime dependency). 32 grid, filled.
- Zest Free undo, redo, minus (24 grid). Aurora's minus.svg had no viewBox and `fill="#000"`; the copy
  has `0 0 24 24` and currentColor.
- Aurora's warning mark (34x29, outline stroked via `stroke: { width }`, exclamation filled).
  Made by the owner and used across the projects that ingest Grille, so it belongs here (confirmed 2026-11-11).
- `THIRD_PARTY_NOTICES` at the repo root (Vidstack MIT and Zest Free texts) added to `package.json`
  `files`.

## Verification

- `scripts/vendor-icons.test.mjs`: each Vidstack path equals `raw/` exactly; 18 exports.
- `npm test` -> 85 passed; `npm run typecheck` clean; `npm run lint` (boundary ok);
  `npm pack --dry-run` lists `THIRD_PARTY_NOTICES`.

## Surprises
