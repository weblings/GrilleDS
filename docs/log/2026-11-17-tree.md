# Tree: controlled expandedKeys, section rows, card rows

Id: 2026-11-17-tree

`Grille-83g.8`. New `Tree` (`aria-label`, `expandedKeys`, `onExpandedChange(Set<string>)`), `TreeSection`
(`id`, `title`, `count?`, `drag?`, `menu?`, children = cards) and `TreeCard` (`id`, `textValue`, children =
row content), on React Aria's Tree (treegrid). A section is a filled pill (`popup-bg-hover`, the step above
the drawer's `popup-bg`, radius-md) with a `slot="chevron"` ghost Button on the right that rotates 180deg when
expanded. A card is a 1px `border-default` outline, radius-sm, indented one level. `drag` is a plain slot the
caller fills (the later drag-and-drop bead wires `slot="drag"` into it). Decisions: sections have no sticky
heading and no empty-state text (Aurora's mock had both, the caller can add them), cards have no selection or
tooltip, and `title` is a string because it is the row's `textValue`. Aurora's two Tree lessons (text fields
swallow row keys, a removed item renders one more frame) apply to caller content and are not handled here.
The chevron's accessible name reads "Expand Alpha" (its label plus the row name).

Fixtures (`src/Tree.fixture.tsx`): "Sections and cards" (Collapse all and Expand all on controlled keys, grip
and menu slots, an empty section, a truncating label) and "In a drawer". Tests: `src/ui.test.tsx` Tree block
(treegrid and rows, expandedKeys drive aria-expanded, Collapse and Expand all, chevron, Arrow and Left/Right
keys, drag slot, axe).
