# Tooltip component

Id: 2026-11-11-tooltip

`Grille-uqg.3`. `Tooltip` and `TooltipTrigger` (`src/Tooltip.tsx`) wrap React Aria's, skinned like
Aurora's `.ef-tip`: popup surface, border, shadow, `radius-sm`, 12px text, no pointer events. New
tokens `size.tooltip.{pad-x,pad-y,max-width}` (10/6/260). Content is any ReactNode, so bold text and a
list work. The trigger must be focusable; README ("Tooltips") says menu rows carry help in
`description` instead. Cosmos fixtures in `src/Tooltip.fixture.tsx`.

## Verification

- Tests in `src/ui.test.tsx`: keyboard focus shows it with rich content and `aria-describedby`, Esc
  hides it, hover shows it. Typecheck, lint and build pass.
- The skin was not compared with `.ef-tip` in a browser in both themes; check that in Cosmos.
