# Switch for Aurora's toggle

Id: 2026-11-23-switch

`Grille-0u5.1`, part of the Aurora dashboard and NUX controls epic (`Grille-0u5`). Aurora's toggle
(`forms.css` `.toggle-row` / `.toggle-switch` / `.toggle-knob`, 7 uses) had no Grille equivalent.

`Switch` (`src/Switch.tsx`) wraps React Aria `Switch` and takes `label`, `isSelected`, `onChange`, `isDisabled`.
The whole row is the hit target, label left and track right. Track is 35x20 with 2px padding, knob 16px, 15px
travel. Off is `--ui-color-control-bg`, on is `--ui-color-strong-bg`, knob is `--ui-color-text-default`, all equal
to Aurora's values, so no new tokens. Disabled is a 0.5 dim. The focus ring goes on the track through the shared
`:focus-visible` rule in `ui.css`, so no per-control ring CSS.

Fixture `Switch` shows off, on, disabled off, disabled on and a row. Focus can't be forced in a fixture, so it
needs a Tab to see.
